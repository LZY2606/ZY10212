# 超声回波裁决台（echo-bench）

本地运行的超声 A 扫回波裁决工作台。检查人员在联动页面上查看**时域波形 / Hilbert 包络 /
闸门 / 声程 / 二维扫描位置**，为闸门内回波保留候选，并区分**设备饱和、重叠（不可分辨）
回波与真实散射**。所有结论与运行操作都以追加事件的形式写入 SQLite，可导出、清空后重放复核。

技术栈：Rust + Axum + SQLite（`rusqlite` bundled）+ 原生 HTML/Canvas/JS 单页，无外网依赖。

## 安装与演示

```bash
cargo fetch --locked
cargo test --locked && cargo run --locked -- --listen 127.0.0.1:5552
```

浏览器打开 <http://127.0.0.1:5552>，页面标题为 **超声回波裁决台**。

默认 SQLite 文件为当前目录 `echo-bench.sqlite3`（可用 `--db` 指定）；数据库为空时自动导入
内置固定夹具并记录一条 `fixture_imported` 事件。

## 数据口径

- **固定夹具**：`fixtures/echo_fixture.json`（编译时内嵌进二进制，离线可复现）。
  - 1024 点，采样间隔 10 ns（100 MHz），5 MHz 载波高斯脉冲，满量程 ±1。
  - 声速 5900 m/s，探头延迟 2000 ns，最小可分辨间隔 200 ns（20 样本）。
  - 5×3 共 15 个扫描位置，间距 2 mm；噪声为固定种子的高斯噪声（RMS 0.012）。
  - 每个位置都有表面（约样本 300）与底面（约样本 560）回波。
  - `p2`：间隔 18 样本（< 20 样本分辨率）的**两个不可分辨近峰** → 一个复合候选。
  - `p8`：幅度 1.7、FWHM 24 的回波被削顶成**饱和平台** → 饱和候选，仅给幅值下界。
  - `p7`：含一个 0.10 幅度的亚阈值散射，用于切换幅值/SNR 阈值时观察候选增减。
- **包络与检测**：时域波形做 FFT 解析信号（零填充到 2 的幂）取幅值包络；另做短滑动平均
  得到“检测包络”以抑制载波波纹，避免把单个脉冲的波纹误判成多个回波。候选幅值始终取自
  原始包络。
- **不可分辨判据**：同一过门区域内，显著峰（≥ 区域最大的 45%）之间若存在明显谷
  （谷值 < 较低峰的 85%）则判为不同回声瓣；间距小于最小可分辨间隔的回声瓣聚成**一个复合
  候选**并保留成员峰，绝不虚拆成两个点。检查人员可对宽回波做**手动拆分**，子候选记录父键
  与左闭右开区间。
- **饱和口径**：原始样本达到 ±1.0 即判饱和；饱和区域因削顶无法分辨峰，只产出一个候选，
  其幅值标注为**下界（UI 显示 `≥`）**，不强行拆点。
- **闸门**：左闭右开区间 `[start, end)`，恰好在边界的峰只属于右侧闸门（如 `[300,340)`
  不含 340，`[340,520)` 含 340）。闸门可在页面调整并重算。
- **深度换算**：
  - 声程（单程仪器时间线）`range_mm = (sample·Δt − probe_delay)·v/2`；
  - 表面相对深度 `depth_mm = range(候选) − range(表面到达)`。
  - 声速 `v` 与探头延迟 `probe_delay` 的版本变化都会改变换算，二者随每条结论快照保存。
  - **当表面到达晚于底面候选（surface_after_bottom）**：该位置标记错误、**不输出任何
    深度值且不绘制倒置深度轴**，必须先修正表面到达时刻。
- **结论保留**：每条裁决保存原始候选样本区间 `[start,end)`、峰样本、幅值/SNR、当时的
  声速与探头延迟（候选快照）。阈值/闸门变化后若候选消失，结论以“历史结论”形式保留快照。

裁决类别：`retained`（保留候选）、`true_scatterer`（真实散射）、`saturation`（设备饱和）、
`overlap`（重叠回波）、`rejected`（排除）。

## 页面操作

- 左侧：二维扫描位置（点选联动 A 扫图；绿点=有结论，紫点=复合，红点=饱和）、闸门编辑、
  缺陷轨迹列表。
- 顶部：修改声速 / 探头延迟 / 阈值类型（幅值或 SNR）/ 阈值大小 / 分辨率并“应用参数”；
  导出、重放、重新导入夹具、清空复位。
- A 扫图：蓝=时域波形，黄=包络，红虚线=阈值，红色底纹=饱和样本，绿线=表面到达；
  候选峰点（红=饱和、紫=复合、蓝=普通/拆分）；右侧为表面相对深度轴（表面晚于底面时隐藏）。
  “在图上点击设置表面到达”后点波形即可修正。
- 候选表：查看归属闸门、声程、深度、幅值/SNR 与标记；可保存裁决与备注、手动拆分复合候选、
  勾选候选。跨相邻位置勾选后“新建轨迹”，服务端要求轨迹成员沿 **4-连通相邻**扫描位置成链。

## 运行记录：导出 / 清空 / 重放复核

- **导出**：`GET /api/events`（页面“导出运行记录”）下载 `echo-bench-run.json`，首条事件
  恒为 `fixture_imported`，其后为所有操作事件。
- **清空并复位**：`POST /api/reset` 清空全部表并重新导入内置固定夹具。
- **重放复核**：`POST /api/replay`，请求体 `{"events":[...]}`；服务端在一个事务内清空库后
  按顺序重放全部事件并重算所有候选/结论，得到与导出时一致的状态。
- **重新导入夹具**：`POST /api/import-fixture`，请求体为夹具 JSON（可传裸 JSON 或
  `{"fixture": "..."}`），用于在清空数据库后导入复核。

事件类型：`fixture_imported`、`surface_corrected`、`config_updated`、`gate_updated`、
`decision_made`、`candidate_split`、`track_put`、`track_deleted`。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全量联动状态（夹具、参数、闸门、各位置波形/包络/候选、轨迹） |
| PUT | `/api/config` | 更新声速/延迟/阈值模式与大小/分辨率 |
| PUT | `/api/gates/{id}` | 更新闸门 `[start,end)`（左闭右开） |
| PUT | `/api/positions/{i}/surface` | 修正该位置表面到达样本 |
| PUT | `/api/positions/{i}/candidates/{k}/decision` | 提交/更新裁决与备注 |
| POST | `/api/positions/{i}/candidates/{k}/split` | 手动拆分宽回波（整数边界） |
| GET/POST | `/api/tracks` | 查询/新建缺陷轨迹 |
| PUT/DELETE | `/api/tracks/{id}` | 更新/删除轨迹 |
| GET | `/api/events` | 导出追加事件日志 |
| POST | `/api/replay` | 清空后重放事件 |
| POST | `/api/reset` | 清空并重新导入内置夹具 |
| POST | `/api/import-fixture` | 导入夹具 JSON |

## 测试

`cargo test --locked` 包含 4 个信号处理单元测试与 10 个端到端 HTTP 测试，覆盖：页面标题、
固定夹具特征、边界峰单侧归属、饱和仅给下界且不虚拆、不可分辨峰保留复合且可手动拆分、
表面晚于底面时禁止深度倒置、阈值切换、结论随声速/延迟版本保留、轨迹相邻约束，以及
导出/重放/清空复位的状态一致性。
