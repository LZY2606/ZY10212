# 超声回波裁决台（Ultrasonic Echo Adjudication Console）

本地单机服务：检查人员在 A 扫波形上为闸门与回波**保留候选**，区分
**设备饱和 / 重叠回波（不可分辨近峰）/ 真实散射**，修正表面对齐、切换
阈值、拆分宽回波，并把多个相邻位置的候选组成同一条缺陷轨迹。

- 技术栈：Rust + Axum + SQLite（`rusqlite` bundled，无需系统 libsqlite）
- 前端：单页 HTML + Canvas，无构建步骤，静态文件内嵌进二进制
- 持久化：SQLite 只存**操作事件日志**，全部裁决状态由固定 fixture 重放得到
- 确定性：波形、包络、检测均为确定性算法；导出附带全部波形的 SHA-256

## 安装与演示

```bash
cargo fetch --locked
cargo test --locked
cargo run --locked -- --listen 127.0.0.1:5552
# 浏览器打开 http://127.0.0.1:5552 ，页面标题为“超声回波裁决台”
```

可选参数：

```bash
cargo run --locked -- --listen 127.0.0.1:5552 --db adjudication.db
# --db :memory: 可使用不落盘的临时数据库
```

## 数据口径（fixture）

固定 fixture 由 `src/fixture.rs` 确定性生成（xorshift64* 噪声 + 高斯调制
5 MHz 脉冲，16-bit ADC 量化），也可通过页面或 `GET /api/fixture.json`
下载完整原始数据：

| 项目 | 取值 |
| --- | --- |
| 采样率 | 100 MHz，2048 样本/扫 |
| 探头中心频率 | 5 MHz |
| ADC | int16，饱和阈值 ±32767 counts |
| 标定版本 | `steel-5900`（5900 m/s，探头延迟 0.20 μs）、`steel-5920`（5920 m/s，0.18 μs） |
| 扫描位置 | 5 个位置，x = 0/5/10/15/20 mm，y = 0 |
| 激发脉冲 | 样本 ≈ 50（位于所有分析闸门外） |
| 表面回波 | 样本 198–202（带亚样本级对齐抖动，可人工修正） |
| 12 mm 缺陷 | 样本 ≈ 608（表面后约 407 样本） |
| 20 mm 底面 | 样本 ≈ 879（表面后约 678 样本） |

五个位置的缺陷回波分别为：干净散射、干净散射、**两个不可分辨近峰**、
**一个可拆分的宽回波**、**ADC 饱和平台**。

### 闸门：左闭右开

默认闸门（样本区间）：

- 表面门 `[150, 300)`
- 检测门 `[350, 660)`
- 底面门 `[820, 960)`

闸门端点一律采用 **左闭右开 `[lo, hi)`**。峰的归属只看峰样本：峰样本
恰好在边界上时**只属于一个闸门**（属于右侧闸门，绝不会同时计入两侧）。
可在页面直接编辑闸门端点，或用 `candidate_split` 之外的 `gate_moved`
事件驱动验收。

### 深度换算与倒置保护

深度以**修正后的表面到达时刻为零深基准**：

```
d(mm) = (c / 2) · (peak_sample − surface_sample) / fs
```

其中 `c` 为当前标定版本声速（m/s），`fs = 100 MHz`；探头延迟是仪器常数，
其影响已包含在表面到达时刻这一基准中。切换声速/延迟版本会立即改变距离轴
与候选的实时深度。每个候选同时保存创建时刻的
`calib_id_snapshot`、`depth_snapshot_mm` 与**原始样本区间 `[start,end)`**，
因此历史结论用的声速/探头延迟版本永远可追溯，不会被后续切换静默改写。

当任一扫描的**表面到达时刻晚于（或等于）其底面候选峰**时，深度轴被判定
为**倒置**：页面显示红色横幅，距离轴停止出结果，并且裁决、拆分、轨迹等
产生深度结论的操作一律被服务端拒绝（HTTP 400），直到表面被重新修正。

### 候选分类规则

检测基于 Hilbert 包络（自研 radix-2 FFT）与阈值连通域（区间同样左闭右开）：

- **单峰 `single`**：一个可分辨波瓣。
- **饱和平台 `saturated`**：连通域内出现 ±32767 样本。幅值字段只代表
  **下界**（界面显示 `≥`），且**禁止拆分**，避免把削顶平台虚拆成两个点。
- **不可分辨复合 `composite`**：同一波瓣内存在两个间隔 4–10 样本、
  高度差 ≤10%、中间无深谷的峰。保留为**一个复合候选**并记录全部子峰，
  绝不强行拆成两个点。
- **拆分峰 `split`**：检查人员对一个宽回波在指定切点拆分，生成两个共享
  切点的半开区间子候选（`[start,cut)`、`[cut,end)`）。

阈值可在**幅值（ADC counts）**与**信噪比（阈值 = 倍数 × 表面前安静窗
`[90,150)` 的包络标准差）**两种口径之间切换。低于阈值的连通域不产生候选。

### 缺陷轨迹

勾选多个候选后可组成轨迹。服务端校验：至少 2 个候选、每个扫描位置至多
贡献 1 个候选，且按横向位置排序后必须是一条**相邻位置不间断链**
（位置间距 ≤ 5 mm）。

## 操作与重放

页面操作（或等价的 HTTP 事件）全部追加到 SQLite `events` 表：

`bootstrap`、`surface_corrected`、`threshold_changed`、`gate_moved`、
`candidate_split`、`candidate_verdict`、`track_grouped`、
`calibration_switched`。

- **导出运行记录**：页面按钮或 `GET /api/export`，得到含 fixture 元数据、
  波形 SHA-256 与完整事件日志的 JSON。
- **清空数据库**：`POST /api/reset`（页面“清空数据库并重导入默认”），
  删除全部事件并写入默认 bootstrap。
- **重新导入复核**：`POST /api/import`，body 为 `{"events":[...]}`。
  导入前会先用固定 fixture **完整试放一遍**整个事件流，任何一步非法都拒绝，
  数据库保持不变；成功后清空旧日志并按顺序写入，再次得到完全一致的状态。

命令行复核示例：

```bash
curl -s http://127.0.0.1:5552/api/export -o run.json
curl -s -X POST http://127.0.0.1:5552/api/reset -H 'content-type: application/json' -d '{}'
curl -s -X POST http://127.0.0.1:5552/api/import \
  -H 'content-type: application/json' \
  --data-binary "$(jq '{events: .events}' run.json)"
```

也可以在服务停止后直接删除数据库文件再启动，等价于从空库重放。

## 自动化测试

`cargo test --locked` 覆盖：

- 首页标题为“超声回波裁决台”；
- 饱和平台幅值只给下界且禁止拆分；
- 不可分辨近峰保留为单个复合候选（不拆成两个点）；
- 左闭右开闸门：边界峰只归一侧，移动 1 样本即换侧；
- 宽回波拆成两个半开子候选，并保留声速版本与深度快照；
- 表面晚于底面时深度轴倒置，裁决被拒绝；
- 轨迹相邻性/同位置唯一性校验；
- 幅值/信噪比阈值切换抑制候选；
- 导出 → 清空 → 导入的完整重放一致性。

## 代码结构

- `src/dsp.rs`：radix-2 FFT、Hilbert 包络、局部极大值；
- `src/fixture.rs`：固定波形 fixture 与标定版本；
- `src/model.rs`：事件溯源状态机、检测/分类、半开闸门、深度与倒置规则；
- `src/store.rs`：SQLite 事件日志、重放、清空、时间戳；
- `src/web.rs`：Axum JSON API 与内嵌静态页；
- `src/static/`：操作页面（`index.html`、`app.js`）；
- `tests/`：端到端 HTTP 集成测试与模型冒烟测试。
